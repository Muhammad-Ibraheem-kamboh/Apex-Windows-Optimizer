# Contributing to Apex Windows Optimizer Pro

Thank you for your interest in improving Apex Windows Optimizer Pro!

## Guidelines
1. **Fork & Branch**: Create a feature branch (`git checkout -b feature/improvement`).
2. **Zero Dependencies**: Keep the core engine 100% dependency-free (no third-party npm packages).
3. **Safety First**: Test all system optimization routines with safe fallbacks and parameterized execution.
4. **Pull Requests**: Submit clean PRs with clear descriptions and before/after verification logs.
